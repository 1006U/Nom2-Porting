# NOM 2 launcher artwork

Place the **original, untouched NOM 2 icon artwork** in this folder before running setup.

Recommended filename:

```text
branding/app_icon.png
```

Also accepted:

- `branding/app_icon.jpg`
- `branding/app_icon.jpeg`
- `branding/icon.png`
- `branding/icon.jpg`

The build script does **not** redraw, crop, recolor, or reinterpret the artwork. It only preserves the aspect ratio, centers the original composition when a square Android icon canvas is required, and generates Android `mipmap-*` sizes.

Do not replace this artwork with an AI-generated recreation.
